วิธีติดตั้งแต่ละแพลตฟอร์ม

⌘ macOS (Intel และ Apple Silicon)

  • 1
    ดาวน์โหลดไฟล์ .dmg ที่ตรงกับรุ่น Mac ของคุณ
  • 2
    ดับเบิลคลิกไฟล์ .dmg เพื่อเปิด
  • 3
    ลาก JBTS ไปยังโฟลเดอร์ Applications
  • 4
    เปิดครั้งแรก: right-click → Open แล้วกด Open อีกครั้งเพื่อข้าม Gatekeeper
⚠️ macOS อาจแสดงคำเตือน "unidentified developer" เนื่องจากยังไม่ได้ยื่น Apple Notarization ให้ใช้ right-click → Open เพื่อข้าม

⊞ Windows

  • 1
    ดาวน์โหลดไฟล์ .zip
  • 2
    แตกไฟล์ ZIP โดย right-click → Extract All
  • 3
    รันไฟล์ JBTS Setup.exe
  • 4
    หาก Windows แสดง SmartScreen: คลิก More info → Run anyway
  • 5
    ทำตามขั้นตอนติดตั้ง แล้ว JBTS จะปรากฏใน Start Menu

📦 Android

  • 1
    ดาวน์โหลดไฟล์ .apk ลงโทรศัพท์
  • 2
    ไปที่ Settings → Apps → Special app access → Install unknown apps
  • 3
    เลือก Browser หรือ File Manager ที่ใช้ดาวน์โหลด → เปิด Allow
  • 4
    เปิดไฟล์ APK แล้วกด ติดตั้ง (Install)
⚠️ Android อาจถามสิทธิ์ติดตั้งจากแหล่งภายนอก เนื่องจาก APK ไม่ได้มาจาก Play Store

คู่มือการใช้งาน JBTS

คู่มือฉบับเต็มครอบคลุมทุกฟีเจอร์ตั้งแต่การเข้าสู่ระบบ บันทึกตู้คอนเทนเนอร์ แชร์ไฟล์ ไปจนถึง Google Sheets

ต้องการความช่วยเหลือ? เปิดคู่มือเพื่อดูคำแนะนำการใช้งานระบบทั้งหมด
เปิดคู่มือการใช้งาน
เลือก Mac ให้ถูกรุ่น Mac รุ่น Intel ใช้ไฟล์ Intel DMG · Mac รุ่น M-series ใช้ arm64 DMG
Windows ZIP ดาวน์โหลด ZIP แล้วแตกไฟล์ก่อน จากนั้นรัน Setup.exe ตามขั้นตอน
